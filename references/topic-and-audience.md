# 选题与受众

## 先判断：这个概念值不值得做成视频

好的计算机科普题，通常同时满足三条：

1. **有一个反直觉的点。** 观众以为自己知道，但一追问就发现不知道。比如“0.1 + 0.2 为什么不等于 0.3”“删除文件为什么还能恢复”“HTTPS 为什么能防偷看”。
2. **机制能被看见。** 能画成流程、层次、状态、位字段、时间线或对照。纯概念（“什么是抽象”）不是不能讲，但需要更具体的入口。
3. **有一个可带走的动作。** 看完能改一个写法、换一个判断、少踩一个坑，或者能向下一个人复述。

只有“重要”不够。重要但无法在 90 秒内建立因果的概念，应该拆成系列，或者换一个更小的切面。

### 适合的题

| 类型 | 例子 | 为什么适合 |
| --- | --- | --- |
| 日常异常 | 0.1 + 0.2、乱码、时区、浮点金额 | 有明确冲突，观众有体感 |
| 隐藏机制 | DNS、TCP 握手、GC、虚拟内存、哈希冲突 | 有清晰的步骤/层次，可动画 |
| 常见误解 | “HTTPS 加密的是整个网页”“删文件就是抹掉数据”“多线程一定更快” | 先立靶再拆，天然有钩子 |
| 权衡 | 缓存、索引、CAP、空间换时间 | 有对照和边界，适合做决策 |
| 编码/表示 | UTF-8、补码、浮点、颜色空间 | 位/字节可以精确画出 |

### 不适合硬塞的题

- **需要一整套前置知识才能开口的题**（如“从零讲清 Transformer”）。拆成系列，或先讲一个可独立成立的小问题。
- **没有稳定结论的题**（“最好的语言”“AI 会不会取代程序员”）。可以讲争论结构，但不能伪装成事实。
- **只能靠念定义的题**（“什么是进程”）。换成一个具体场景：“你点了播放，为什么电脑还能同时回消息？”
- **依赖实时数据/价格的题**。数据会过期；要么明确日期，要么换稳定机制。

## 受众决定省略什么

| 受众 | 默认知道 | 可以省略 | 必须补上 |
| --- | --- | --- | --- |
| 好奇的大众 | 会用手机/电脑，不写代码 | 二进制、内存、协议 | 每个术语的一句人话；一个生活类比；不要出现代码，或只出现一行 |
| 会写代码的人 | 变量、函数、基本命令行 | 编程入门 | 具体版本/默认值；真实输出；边界条件 |
| 学生/面试向 | 基础数据结构 | 语言语法 | 推导步骤；复杂度；常见误区；可手算的例子 |

写片前用一句话写清受众，例如：“会写 Python、但没学过浮点的数据分析师。” 这句话决定术语密度，不要写“所有人”。

## 前提阶梯

列出观众必须知道的 3–6 件事，逐条决定：**片内解释、用类比绕过、还是直接删掉。**

```text
要看懂“0.1 + 0.2”：
1. 小数可以写成二进制 —— 片内用 0.5 = 0.1₂ 对照解释
2. 计算机用固定位数存数 —— 片内用 64 个格子的位条解释
3. 舍入会发生 —— 片内用“53 位以后四舍五入”解释
4. IEEE 754 的历史 —— 删掉，只留一句“这是标准”
5. 其他舍入模式 —— 删掉，页脚注明“默认 round-to-nearest”
```

如果第 1 条就需要 40 秒，说明这个题对当前时长太大：换更小的切面，或把时长升到 3 分钟。

## 标题与钩子

标题只做一件事：让目标观众知道“这和我有关”。推荐三种：

- **具体问题**：“为什么 0.1 + 0.2 不等于 0.3？”
- **具体数字/对比**：“一个汉字，在 UTF-8 里占几个字节？”
- **具体后果**：“你的密码，可能根本没被加密。”

避免：“浅谈……”“一文读懂……”“你真的了解……吗？” 这些标题没有信息，也没有承诺。

钩子在前 3 秒发生，最晚不超过 8 秒：

1. **先给结果**：真实输出、错误截图、一个反常识的数字。
2. **再给承诺**：这支片子会解释什么，不解释什么。
3. **不要开场白**：“大家好，欢迎来到频道”会浪费最贵的 3 秒。

钩子之后要尽快给“为什么值得看”：一个代价、一个日常场景、一个会改变行为的判断。

## 时长与范围

| 时长 | 能讲什么 | 结构 | 字数（中文口播） |
| --- | --- | --- | --- |
| 45–60s | 一个反转 + 一个机制 + 一句结论 | 钩子 → 机制 2–3 步 → 回扣 | 220–300 字 |
| 75–100s | 一个机制 + 一个证据 + 三条建议 | 钩子 → 转折 → 机制 → 验证 → 小结 | 350–480 字 |
| 3–6min | 一个机制 + 历史/权衡 + 多个证据 | 分章，每章 40–70 秒，章末小结 | 900–1600 字 |

字幕字数按中文 4–5.5 字/秒估算；TTS 实际可能更慢。**先写台词再定时长，不要先定时长再硬塞。**
